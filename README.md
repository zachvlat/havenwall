# HavenWall

**HavenWall** is an Android application that lets you browse and set beautiful wallpapers on your device directly from [WallHaven](https://wallhaven.cc/). Built with Kotlin and powered by the WallHaven API, it offers a clean, fast experience for discovering and applying high-quality wallpapers.

## Features

- Search wallpapers by keywords.
- View wallpaper tags.
- Set wallpapers directly from the app.
- Favorites list for quick access.
- Light and dark theme support.
